# 光伏组串IV扫描台

扫描员提交组串开路电压、短路电流与填充因子。写入后走 PostgreSQL 通知通道叫醒独立工人，工人不轮询空转。填充因子不低于 0.72 为合格，否则衰减。页面是 Vue 3。

顶栏可进**昼夜差专页**，交班时核对各组串白天与夜里填充因子是否差得离谱：

- **上格 · 对照窗**：按组串选昼窗、夜窗。默认昼 `[06:00,18:00)`、夜 `[18:00,次日06:00)`，窗为左闭右开，夜窗跨零点（终点可填到 30）。只有扫描员（scanner）可改窗；巡视账号（watcher）只读，不能改窗也不能报送。每组串只保留一笔窗宽，后改的覆盖先改的（主键 upsert）。
- **中格 · 昼夜差与样本点**：按串列出昼/夜样本数、均值、昼夜差和具体样本点。结果始终按各串当前对照窗**即时重算**，总表里手填的一列数字不作为结果。只有 `status=done` 的办结读数进样本，待处理读数一律剔除；落在两窗外的钟点计入"窗外点"，不进任一侧。任一侧无样本时昼夜差留空。
- **下格 · 口径（只读）**：时区、窗口、样本与重算口径。

把故意拉大昼夜差的组串的对照窗收到没有读数的区段后，该串差值应变平或整列留空，窗外点计数相应增加。

## 技术栈

- 后端：Litestar、Uvicorn、psycopg 同步写入
- 工人：`LISTEN/NOTIFY` 唤醒后认领
- 前端：Vue 3、Vite、nginx 反代 `/api`
