# 光伏组串IV扫描台

扫描员提交组串开路电压、短路电流与填充因子。写入后走 PostgreSQL 通知通道叫醒独立工人，工人不轮询空转。填充因子不低于 0.72 为合格，否则衰减。页面是 Vue 3。

顶栏可进入**昼夜差专页**，供交班前核对各组串白天与夜里填充因子是否差得离谱：

- 上格调对照窗（起始日期 + 窗宽天）；
- 中格按组串列出窗内白天/夜里样本点、均值与昼夜差，随窗**实时重算**，总表不设手填列；
- 下格为只读口径说明。
- 只有已办结（done）读数进样本，待处理读数不参与；白天/夜里任一侧无样本点时昼夜差留空。
- 扫描员可调对照窗，巡视口令只读（不能改窗、不能报送）。每个组串只存一笔对照窗，两人抢改也只留一笔窗宽。

## 技术栈

- 后端：Litestar、Uvicorn、psycopg 同步写入
- 工人：`LISTEN/NOTIFY` 唤醒后认领
- 前端：Vue 3、Vite、nginx 反代 `/api`

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/day-night-diff` | 各组串按当前对照窗重算的昼夜差与样本点（登录可见） |
| PUT | `/api/compare-windows` | 设置/更新某组串对照窗（仅扫描员，按组串 upsert 只留一笔） |

## 启动

```bash
cd projects/22-pv-string-iv-scan
docker compose up --build
```

健康检查：`GET http://localhost:8202/api/health`

## 种子

| 组串 | 填充因子 | 结论 |
|------|----------|------|
| 阵列A-串03 | 白天 0.77–0.79 / 夜里 0.71–0.72 | 昼夜差对照 |
| 阵列B-串11 | 白天 0.61–0.63 / 夜里 0.58–0.59 | 衰减，昼夜差对照 |
| 阵列C-串05 | 无读数，仅有对照窗 | 昼夜差留空示例 |

白天取北京时间 10 点、夜里取 22 点的办结读数，对照窗默认覆盖最近三天。
